RGB-split glitch headline. Signature brand effect — use on hero words and hover moments, never on body copy.

```jsx
<GlitchText as="h1" style={{fontSize:'6rem'}}>BEYOND HUMANOID</GlitchText>
<GlitchText font="glitch" always>ONLINE</GlitchText>
```

Glitches on hover by default; pass `always` for a persistent effect. `font`: `display` (Iceland, default), `glitch` (Rubik Glitch), `serif`.
