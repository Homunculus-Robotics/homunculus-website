Default content container. Dark surface, hairline border, optional blueprint grid, glow, and technical corner ticks.

```jsx
<Card grid corners>
  <h3>Embodiment IV</h3>
  <p>Four-arm surgical lattice.</p>
</Card>
```

Props: `grid` (blueprint texture), `glow` (phosphor instead of shadow), `corners` (corner ticks, default on), `padding`.
