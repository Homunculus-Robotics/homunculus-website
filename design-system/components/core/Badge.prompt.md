Small mono status chip / label. Use for tags, statuses, and section eyebrows-as-pills.

```jsx
<Badge tone="green" live>Embodiment online</Badge>
<Badge tone="gold">Series A</Badge>
<Badge tone="neutral">Non-humanoid</Badge>
```

Tones: `green` (default), `gold`, `neutral`, `error`. Set `live` for a pulsing status dot.
