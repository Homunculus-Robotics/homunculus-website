Primary action control — use for any button or CTA in Humunculus surfaces.

```jsx
<Button variant="primary" mono>Request access</Button>
<Button variant="outline" size="lg">View embodiments</Button>
<Button variant="signal">Talk to us</Button>
```

Variants: `primary` (phosphor green, default), `signal` (gold — reserve for one key CTA per view), `outline`, `ghost`. Sizes `sm|md|lg`. Set `mono` for uppercase instrument-label styling. Set `as="a"` + `href` to render a link.
